# BaritoneBots

[English](README.md)

Боты для Minecraft Java 26.2, которые ходят и работают через Baritone 1.19.0. Каждый бот — настоящий клиент без окна. Управление — из веб-панели менеджера на том же ПК, где запущены боты. Нажал кнопку — бот дошёл до сундука, забрал броню, надел её и пошёл копать.

Проверено 2026-10-04 на локальном Paper 26.2 build 129, офлайн-режим, плоский мир:

| Задача | Результат |
|---|---|
| Запуск бота до входа на сервер | 50 s |
| `goto` на 22 блока | 4 s, остановился в 2 блоках от цели, допуск 2 |
| `take` из сундука | забрал 4 предмета брони, меч, лопату и 8 из 16 хлеба |
| `equip` | надел 4 предмета брони |
| `mine` земли, цель 6 | собрал 9, лопату выбрал сам |
| `deposit` | сдал 9 земли, броню и хлеб оставил по правилу `keep` |

## Из чего состоит

| Часть | Что делает |
|---|---|
| `manager` | Один jar. Ставит Minecraft, Fabric и моды через HeadlessMC 2.10.0, запускает и перезапускает ботов, держит очереди задач, сценарии, наборы снаряжения и сведения о мире. Отдаёт веб-панель на `127.0.0.1:8765`. |
| `bot-mod` | Fabric-мод внутри каждого бота. Выполняет задачи через API Baritone, сообщает состояние, сам логинится, переподключается, ест, отбивается от мобов и встаёт после смерти. |
| `common` | Протокол между ними и чтение схематик `.schem` и `.litematic`. |

Связь менеджера с ботами идёт по TCP на `127.0.0.1`. Порт на сервере не нужен, сервер видит ботов как обычных игроков.

## Сколько потребляет

Замер на одном боте, heap ограничен 1024 MB:

| Процесс | RAM |
|---|---|
| игра бота | 900 MB, из них heap 300–430 MB |
| лаунчер HeadlessMC | 102 MB на бота |
| менеджер | 111 MB на всех |

В простое бот тратит 0.07 секунды CPU в секунду. На 5 ботов выходит около 5 GB RAM. Окна нет: мод не рисует кадры, не играет звуки и держит дальность прорисовки в 4 чанка. Память на бота задаётся пресетом eco 768 MB, normal 1024 MB или performance 2048 MB.

## Запуск

1. Поставь Java 25, например Temurin.
2. Скачай `baritonebots-manager-<версия>.jar` из Releases в пустую папку.
3. Запусти:
   ```bash
   java -jar baritonebots-manager-0.1.0.jar
   ```
   Менеджер откроет панель в браузере. Адрес с токеном доступа он печатает в консоль.
4. В панели: «Настройки» → «Серверы» → адрес сервера. «Боты» → добавить ботов с офлайн-аккаунтами.
5. «Настройки» → «Окружение» → «Установить». Менеджер скачает HeadlessMC, Fabric 0.19.5, Fabric API, Baritone, FerriteCore и Minecraft 26.2.
6. Запусти ботов и давай им задачи из карточки бота.

Данные лежат в `BaritoneBots-data` рядом с jar: настройки, токен панели, пароли ботов, скачанные файлы. Папку не публикуй.

## На своём сервере

* **AuthMe / nLogin.** Бот видит в чате просьбу зарегистрироваться или войти и сам вводит `/register` или `/login`. Пароль менеджер генерирует для каждого бота. Шаблоны фраз и команд настраиваются в профиле сервера.
* **GrimAC.** Если сервер твой, исключи ботов через LuckPerms:
  ```
  lp creategroup bots
  lp group bots permission set grim.exempt true
  lp user Bot1 parent add bots
  ```
  Grim проверяет `grim.exempt` каждый тик, поэтому перезаходить не нужно. После снятия права бот должен перезайти. В офлайн-режиме право привязано к нику, так что дай ботам длинные пароли AuthMe.
* **Чужие серверы.** Обход античитов в проекте не делается. Использование Baritone на чужом сервере — на твой риск и по правилам этого сервера.

## Задачи

`goto`, `goto_player`, `follow`, `explore`, `mine`, `farm`, очистка области, `collect_drops`, `take`, `deposit`, `inspect`, `equip`, `eat`, `recover` (вернуться за вещами после смерти) и `baritone` — любая команда Baritone без `#`. Шаги менеджера: `kit` (набор снаряжения из сундуков с ролью «kit»), `deposit_storage`, `home`, `wait`, `goto_waypoint`. Из этих шагов собираются сценарии, их можно повторять по кругу.

## Чего пока нет

* Совместных проектов: стройки по схематике несколькими ботами, автоматических ролей. Это второй этап.
* Крафта, плавки, животных и сортировки склада.
* Плагина-компаньона для сервера: журнал блоков, откат, Prism.
* Microsoft-аккаунтов для лицензионных серверов. Сейчас только офлайн.
* Нескольких ботов в одной JVM. Baritone так не умеет, поэтому каждый бот — отдельный процесс примерно на 1 GB.
* Проверки на живом SoloCraft: всё измерено на локальном тестовом сервере.

## Сборка

```bash
./gradlew build
```
